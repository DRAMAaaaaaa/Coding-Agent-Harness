# 历史过程材料索引

本目录保存项目开发中已经结束、被取代或仅供追溯的过程证据；它不是当前产品使用说明，也不替代根目录的 `SPEC.md`、`PLAN.md`、`SPEC_PROCESS.md` 与 `AGENT_LOG.md`。

- `specs/`：已批准的 brainstorming 设计快照。
- `plans/`：历史实施计划；其中可能存在后来被新计划替代的版本，阅读时应以根目录 `PLAN.md` 的当前状态为准。
- `ledgers/`：MVP 问题和延期事项的历史台账，保留其当时的结论与证据链接。
- `reports/`：Git 已跟踪的实现、审查和冷启动报告。中间报告不代表最终交付状态，应结合提交历史、根过程文档和最新验证结果判断。

本次只归档 Git 已跟踪的报告。开发会话中从未跟踪、受忽略或只存在于本机的临时报告不会被补造或移动；缺少这类文件时，应以 Git 提交、根过程文档和可复现的验证输出为准。

历史材料可能保留“当时路径”、旧计划链接和迁移映射，以忠实反映当时的决策与执行环境。这些文字不是当前导航入口，也不应被理解为文件仍位于旧路径。
